# Defective odd log-logistic modified Gompertz mode

This repository contains the code and data used in the article:

**Prataviera, F., Almeida, F. M., Mota, A. L., & Cordeiro, G. M. (2026).**  
*Defective odd log-logistic modified Gompertz model with applications to medical data*.  
*Communications in Statistics - Simulation and Computation*.  
https://doi.org/

## Overview

This repository provides the scripts and data used to reproduce the analyses presented in the article, including model fitting, simulations, and applications.
